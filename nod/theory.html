Named class specifications

TypeDef H:((x:T)->U); declares a checked class-local contract, not a field. static func H Owner.prove { return ...; } implements its named binders. Ordinary funcs remain non-dependent and class-owned. Checks target named declarations and TypeDef aliases, not anonymous functions or types. This page uses the runtime's specification checker with execution disabled.

What is checked

Sort(0) : Sort(1), Sort(1) : Sort(2), and so on. Sort(0) corresponds to Lean's Prop; Sort(1) to Type 0. Function universes use the numeric imax rule, including impredicative Prop.


        
Identity versus computation

        
Repeated descriptions create distinct nodes. Alpha-renamed binders can still compare equal semantically. Beta substitution of named implementations and delta unfolding of aliases compare normalized structure, not node IDs.

        
Not full Lean: named class checks do not add induction, general proof elimination, symbolic universes, theorem search, or a general termination prover. Work is bounded.
