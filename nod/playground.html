Generated propositions

A generator returning Prop creates an immutable proposition description, not its proof. Any(A,b) and Exists(A,b) store the predicate b; TypeDef B names its type. Universal evidence supplies every b(x); existential evidence supplies a witness and b(witness). These are class-defined rules, not native Lean notation.

Runtime objects / aliases

Type x; allocates a fresh default object. Explicit nil resolves to the shared mutable Type(nil) object, shown with "nil":true. Nested class defaults reference their type's nil object.
